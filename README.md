## 3. MRA-IDN 论文需要读到什么程度

### 3.1 一句话解释

输入一张模糊的低分辨率遥感图像，先用普通插值得到平滑底图，再让一个较轻量的卷积神经网络学习道路边缘、建筑线条和纹理等细节，最后把两部分相加，生成更清晰的高分辨率图像。

### 3.2 它解决的问题

- 普通插值只能把图片放大，容易模糊边缘和纹理；
- 大型深度网络效果较好，但参数、计算量、显存和运行时间较高；
- 论文希望兼顾“恢复质量”和“模型轻量化”。

### 3.3 整体方法

```text
低分辨率 RGB 图像
        |
        |-- 低频分支：双线性插值 -------------------|
        |                                           |
        |-- 高频分支：3x3 卷积                      |
                     -> 多个 MRA-IDG                |
                     -> 特征融合与跳连               |
                     -> 最近邻插值 + 卷积上采样      |
                     -> 预测细节残差 ----------------|
                                                    |
                                                 两者相加
                                                    |
                                             高分辨率图像
```

最重要的理解：

- 低频分支负责大体颜色、亮度和平滑结构；
- 高频分支负责边缘、细线和纹理；
- 更准确地说，CNN 学习的是在插值底图上“还需要补上的细节残差”；
- 论文没有用 FFT 或严格滤波器显式分割高低频。

### 3.4 三个核心名词

#### MRA-IDG

网络反复堆叠的主干模块，由 MSR-ID 和 HFCA 组成。

#### MSR-ID

把特征通道拆成几组，通过不同深度的卷积观察不同范围的图像结构，再重新融合。目的是以较少参数获得多尺度特征。

这里的“信息蒸馏”不是大模型教小模型的知识蒸馏，而是通道拆分、逐步加工和融合。

#### HFCA

一种通道注意力。除了计算各通道平均值，还计算标准差，借此更加关注变化较明显的边缘和纹理特征。

这里的“注意力”是给不同特征通道分配权重，不是 Transformer 自注意力。

### 3.5 实验信息

- AID：训练集；
- 从 RSSCN7 抽取 30 张作为 Test30 验证集；
- WHU-RS19、RSSCN7：测试集；
- 测试 4 倍和 8 倍放大；
- 使用 PyTorch 1.5、Ubuntu 18.04.5 和 NVIDIA RTX 2080；
- 指标包括 PSNR、SSIM、参数量、FLOPs、GPU 显存和推理时间。

论文摘要报告：

- 4 倍放大时 PSNR 可达 31.59 dB、SSIM 0.824；
- 8 倍放大时 PSNR 可达 27.39 dB、SSIM 0.668；
- 与 MHAN 相比，参数量降低约 75%。

这些结果只适用于论文的数据集、退化模型和测试条件，不能理解成所有真实卫星图像都能达到。

### 3.6 论文局限

作者明确指出：

- 训练主要使用 bicubic 下采样这一种人工退化方式，真实遥感图像更加复杂；
- 主要针对光学 RGB 遥感图像，不能直接证明适用于高光谱、SAR 等类型。

从集成电路角度还应注意：

- 论文没有进行 FPGA 或 ASIC 部署；
- 没有报告定点量化、FPGA 功耗、吞吐率、片上存储和外部带宽；
- 参数少、FLOPs 少不等于一定适合 FPGA；
- HFCA 中的标准差和通道权重计算可能带来额外硬件代价。

### 3.7 阅读顺序

### 5.3 建议完成的两个小练习

练习一：计数器。

- 输入：时钟、复位、使能；
- 输出：计数值；
- 目标：理解时钟沿、寄存器和非阻塞赋值。

练习二：简单乘加模块 MAC。

```text
acc_next = acc + a * b
```

- 目标：理解乘法和累加；
- 意义：卷积层和全连接层的核心计算都是大量乘加；
- 当前只需仿真正确，不追求高性能、流水线或上板。

每个练习应保留：

- Verilog 源码；
- Testbench；
- 仿真波形截图；
- 一段自己遇到的问题和解决过程。

## 9. 推荐向老师提出的问题

优先选择一个主问题，不要一次全部抛出。

### 最推荐的问题

> 老师，我加入了 AI 组，同时开始了解 FPGA。以我现在刚结束大一的基础，您建议我先从 Python、PyTorch 和神经网络复现入门，还是同步学习 Verilog？课题组有没有适合低年级学生连接这两方面的小任务？

### 关于 MRA-IDN

### 关于 FPGA 部署

> MRA-IDN 主要在 GPU 上比较参数量、FLOPs 和推理时间。如果进一步部署到 FPGA，主要瓶颈更可能是卷积、特征图存储，还是 HFCA 中的标准差和通道权重计算？这是否适合作为本科生后续的学习项目？

### 关于本科生切入点

> 如果低年级学生参与，您更建议从论文复现、数据处理、竞赛基础模块，还是 Verilog 仿真开始？有没有师兄师姐目前在做适合旁听或协助的项目？

## 10. 表达诚意时需要注意

### 可以说

- “我初步阅读了摘要、网络结构和结论”；
- “我目前的理解是……”；
- “具体模块和公式还没有完全看懂”；
- “我希望从基础任务开始”；
- “如果暂时没有项目，也希望获得一份学习建议，之后再向您汇报”。

### 不要说

- “我已经深入研究了您的论文”；
- “我精通 STM32、FPGA 或人工智能”；
- “老师直接给我一个论文题目”；
- “这个算法很适合 FPGA”，除非经过硬件分析；
- 为显得专业而连续堆砌 MRA-IDG、HFCA、EPC-LIF 等名词。

真正的诚意不在于一次说多少术语，而在于老师给出建议后能够执行，并在两三周后带着结果汇报。
